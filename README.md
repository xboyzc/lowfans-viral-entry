# 低粉爆款入口

一套面向实体老板、创始人 IP 和短视频运营者的“低粉爆款”选题查找方法，并配套可直接浏览的网页操作指南。

> 核心原则：学选题，不搬内容；学结构，不抄原句。

[在线体验（Cloudflare Pages）](https://lowfans-radar.pages.dev/)

## 项目缘起

本项目由三条短视频运营参考内容整理而来。最初目标是建立一个能够按行业搜索低粉爆款、查看原视频、继续做内容拆解与二创的选题库。

经过实际验证后，项目先聚焦在最可靠、最容易复用的一步：把“巨量算数 / 抖音指数”和“热点宝”里的低粉爆款查找方法，整理成任何人都可以照着操作的网页流程。

当前版本完成了以下工作：

- 将零散的短视频讲解整理成结构化步骤；
- 使用真实操作截图，而不是虚构界面；
- 完整展示抖音指数的六步查找流程；
- 将热点宝整理为同逻辑的文字版流程，避免重复图片；
- 给出首次查询可直接使用的筛选参数；
- 增加“选题爆”与“作者本身爆”的判断清单；
- 使用 Cloudflare Pages 作为默认公开部署入口。

## 核心方法

### 方法一：抖音指数 / 巨量算数

1. 在抖音搜索“抖音指数”，进入官方数据工具；
2. 点击底部“榜单”；
3. 选择与账号最接近的行业垂类；
4. 切换到“低粉爆款”；
5. 统计周期优先选择“周榜”；
6. 从榜单中选择视频指数高的内容，至少收集 3—5 条再总结共性。

### 方法二：热点宝

热点宝与巨量算数的核心筛选逻辑一致：

```text
进入爆款视频 → 选择垂类 → 低粉爆款 → 时间周期 → 高数据视频
```

先看近 1 天寻找正在起量的内容，再用近 3 天或近 7 天验证其稳定性。同一个选题如果被多个低粉账号做出高数据，参考优先级更高。

## 推荐筛选参数

| 维度 | 建议值 | 用途 |
| --- | --- | --- |
| 时间 | 近 3 天 | 优先发现正在起量的内容 |
| 粉丝量 | 3,000—10,000 | 排除大号粉丝基础带来的数据优势 |
| 视频时长 | 15—60 秒 | 适合口播、实体老板与创始人 IP |
| 排序 | 点赞量最高 | 进一步比较赞粉比和账号日常数据 |

## 最终判断清单

找到候选视频后，不要立刻照着拍。先检查：

- 点赞是否明显高于账号粉丝量？
- 这条视频是否明显高于该账号的日常数据？
- 同一选题是否有其他低粉账号也做出高数据？
- 自己是否有真实经历、案例或不同观点可以加入？

只有同时满足“数据异常突出”和“内容能够原创改写”，才值得进入选题库。

## Skill 使用方式

仓库根目录提供标准 [`SKILL.md`](./SKILL.md)。将仓库作为 Skill 使用时，它会指导执行者：

- 选择巨量算数或热点宝作为入口；
- 按统一口径筛选低粉爆款；
- 收集候选视频并记录核验信息；
- 判断选题是否具有跨账号复用价值；
- 将可复用结构转化为原创短视频方向。

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开 `http://localhost:3000`。

如果需要试验仓库中的 AI 拆解 API：

```bash
cp .env.example .env.local
```

然后在 `.env.local` 中填写自己的 `DEEPSEEK_API_KEY`。密钥只能放在本地或 Cloudflare Secret 中，不要提交到 GitHub。

## Cloudflare 部署

本项目默认使用 Cloudflare 作为上线基础设施。

```bash
npx wrangler login
npm run deploy:cloudflare
```

当前 Cloudflare Pages 部署为静态操作指南。`app/api` 中的搜索和 AI 拆解路由属于后续动态能力，正式启用时应迁移到 Cloudflare Workers，而不是把密钥打包进前端。

## 内容边界

- 不伪造粉丝数、点赞量、评论量或账号信息；
- 无法核验的数据必须明确标注“待核验”；
- 不批量搬运视频，不照抄原句和具体案例；
- 截图和平台名称仅用于操作教学与方法说明，相关权益归原权利人所有；
- 抖音页面与入口名称可能更新，请以 App 当前界面为准。
